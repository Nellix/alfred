# Security policy

Alfred is an experimental mobile agent and has not completed a production security audit. Do not use
it to automate banking, wallets, authentication, payments, purchases, deletion, or other high-impact
workflows.

Please report exploitable vulnerabilities privately through GitHub's **Report a vulnerability**
feature when it is enabled. Do not include real credentials or user data in a report. See
[docs/security.md](docs/security.md) for the trust model and current limitations.
